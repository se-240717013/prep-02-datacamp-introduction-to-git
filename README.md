# PREP-02: DataCamp Introduction to Git

## English

Complete the DataCamp course [Introduction to Git](https://app.datacamp.com/learn/courses/introduction-to-git).
It introduces version control and the basic Git workflow.

After completing the course:

1. Fill in completion.md with the requested details.
2. Answer the questions in answers.md in your own words.
3. Commit and push the completed files before the deadline announced in DYS.

If DataCamp shows a completion record or certificate link, include it. If it does
not, leave that field as Not available; do not invent a link.

---

## Türkçe

[Introduction to Git](https://app.datacamp.com/learn/courses/introduction-to-git)
DataCamp eğitimini tamamlayın. Eğitim sürüm kontrolünü ve temel Git çalışma akışını
tanıtır.

Eğitimi tamamladıktan sonra:

1. İstenen bilgileri completion.md dosyasına yazın.
2. answers.md dosyasındaki soruları kendi cümlelerinizle cevaplayın.
3. Tamamlanan dosyaları DYS'de duyurulan son tarihten önce commit edip pushlayın.

DataCamp bir tamamlama kaydı veya sertifika bağlantısı gösteriyorsa ekleyin.
Göstermiyorsa ilgili alana Not available yazın; bağlantı uydurmayın.
