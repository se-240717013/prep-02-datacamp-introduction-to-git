# Answers

Write short answers in your own words.

1. Why is version control useful when working on files or code?

   Answer: It tracks changes over time, makes it easy to revert to earlier versions if something breaks, and allows multiple people to collaborate seamlessly without overwriting each other's work.

2. What is the difference between a local Git repository and a remote repository?

   Answer: A local repository is stored and managed entirely on your own computer for offline work, while a remote repository is hosted on a central server (like GitHub) to share code, collaborate, and keep backups.

3. What information does a commit help you preserve?

   Answer: A commit preserves a snapshot of the modified files, a descriptive commit message explaining the changes, author information, a timestamp, and a unique hash identifier.
